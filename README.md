## 🌟 Ключевые Возможности Программного Комплекса

### 1. ⚛️ Вычислительное физическое ядро (10 Гц RK4)
- **Численное моделирование:** Математическая модель реакций, гидродинамики и массообмена в реальном времени (`10 Гц`) методом Рунге-Кутты 4-го порядка.
- **Уравнения процессов:**
  - Гидродинамика центробежных насосов $H(Q) = H_0 - A Q^2$.
  - Теплообмен в печи П-1 по логарифмическому температурному напору (LMTD).
  - Массообмен ректификационных колонн К-1/К-2 по уравнениям Соудерса-Брауна.
  - Оценка риска кавитации по критическому упругости паров $P_{vap}(T)$.

### 2. 🔌 Промышленный протокол Modbus TCP (Порт 5020)
- Встроенный сервер **Modbus TCP Server** (holding registers / input registers).
- Поддержка подключения реальных промышленных контроллеров (PLC Siemens, Schneider, ОВЕН) и SCADA-систем (Simple-One, MasterSCADA, TRACE MODE).

### 3. 🛡️ Трехуровневая подсистема безопасности и диагностики
- **ПАЗ (Противоаварийная Защита):** 6 автоматически срабатывающих блокировок (PAZ-1..PAZ-6) при критических температурах, давлениях и солесодержании.
- **🧪 LIMS (Лабораторный Модуль):** Автоматический забор проб по ГОСТ 21534, ГОСТ 2177, ГОСТ 6356, ГОСТ 6258 (Сырая нефть, Обессоленная нефть, Бензин, Керосин, Мазут).
- **🔊 КОМПАКС (Виброакустика):** Динамический расчет виброскорости подшипников по ISO 10816-3 (Zone A..D) с выявлением дефектов колец и разрушения.

### 4. 🧠 ИИ-Наставник & Компьютерное Зрение (TensorFlow.js)
- **AI Copilot:** Локальный экспертный агент, генерирующий регламентные подсказки в реальном времени.
- **Computer Vision (Offline Neural Net):** Детектор дисциплины оператора по веб-камере (контроль внимания, определение смартфона, усталости).

### 5. 💰 Экономический модуль TCO (Реформа 2026 года)
- Учет стоимости простоя установки (**4.8 млн руб / час**).
- Моделирование налога на прибыль (25%), НДС (22%) и налоговой экономии за счёт амортизации оборудования (возврат 25% от CapEx).

## 🚀 Быстрый запуск (1-Click Launch)

### Требования:
- Windows 10/11 (64-bit)
- Python 3.10+

### Запуск одной кнопкой:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/username/ktk_elou_avt_core.git
   cd ktk_elou_avt_core
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите симулятор:
   - Двойной клик по **`ЗАПУСК_КТК_СИМУЛЯТОРА.bat`**  
   - Или из консоли:
     ```bash
     python run_ktk_system.py
     ```
4. Браузер автоматически откроет дашборд по адресу: **`http://127.0.0.1:8888/frontend/index.html`**

│   └── js/
│       ├── svg_renderer.js    # Рендерер 2D P&ID мнемосхемы
│       ├── three_scene.js     # Рендерер 3D WebGL сцены (Three.js)
